## 📌 Problem Statement

Most people write vague, context-free prompts and get mediocre AI outputs.  
**SmartPrompt AI** analyzes your prompt in real-time and rewrites it with role context, format instructions, tone cues, and specificity — turning weak prompts into high-quality ones instantly.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🧠 **Context Injection** | Adds missing role, tone, and output format automatically |
| 🎯 **Clarity Scoring** | Rates and improves specificity before & after optimization |
| ⚡ **5 Optimization Modes** | General, Technical, Creative, Research, Business |
| 📋 **Improvement Tips** | Shows exactly what changed and why |
| 🔄 **Re-optimize** | Iteratively refine until the prompt is perfect |
| 🛡️ **100% Client-Side** | No data leaves your browser — fully private |

## 🧠 How It Works

1. **User inputs** a raw, unoptimized prompt
2. **Mode selection** sets the optimization style (Technical, Creative, etc.)
3. **Pattern Analysis** checks for missing: role context, output format, length hints, tone cues, vague language
4. **Prompt Rewriting** injects the missing elements intelligently
5. **Quality Score** shows estimated improvement percentage
6. **Improvement Tips** explain every change made

### Optimization Example

**Before:**
```
write me a blog post about AI
```

**After (Technical mode):**
```
You are a senior software engineer with 15 years of industry experience.

Write me a blog post about AI. Include code examples where relevant. 
Use markdown for formatting. Be thorough but concise — aim for 200–400 words 
unless the topic demands more.
```
